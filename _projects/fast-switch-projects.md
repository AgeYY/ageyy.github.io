Switching projects can interrupt your workflow when VS Code reloads the workspace each time. Fast Switch Projects keeps projects open in separate windows and lets you move between them with keyboard shortcuts.

![Reordering project slots and switching between VS Code windows]({{ '/assets/img/projects/fast-switch-projects-demo.gif' | relative_url }}){: .img-fluid .rounded }

Assign projects to ordered slots, jump directly to slots 1–9, or cycle through your open projects. You can drag slots into a new order and export your project setup to reuse on another machine.

[GitHub, installation, and usage guide](https://github.com/AgeYY/fast-switch-projects)

Built on [Projects by L13](https://github.com/L13/vscode-projects), with ordered slots and switching between open windows.
